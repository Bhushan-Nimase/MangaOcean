# MangaOcean 🌊

## Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/Bhushan-Nimase/MangaOcean.git
cd MangaOcean
```

### 2. Install Dependencies

Navigate to the frontend and backend folders and install their dependencies.

**Frontend:**

```bash
cd frontend
npm install
```

**Backend:**

Open the backend project in Visual Studio and restore the NuGet packages.

### 3. Run the Project

**Frontend:**

```bash
npm run dev
```

**Backend:**

Run the backend using Visual Studio or the .NET CLI.

```bash
dotnet run
```
